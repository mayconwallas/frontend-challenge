# Kurio NFT Marketplace

Frontend technical challenge developed with React and TypeScript.

The project implements an NFT marketplace based on the provided Figma design, with a focus on frontend architecture, responsive design, accessibility, REST integration, asynchronous state management, real-time updates and automated testing.

## Tech Stack

- React
- TypeScript
- Vite
- TanStack Router
- TanStack Query
- Axios
- Tailwind CSS
- shadcn/ui
- MSW
- Socket.IO
- Playwright
- Lighthouse

## Architecture

The project follows a feature-based architecture with clear separation between UI, domain features, API services, mocks and shared infrastructure.

```text
src/
├── app/
├── components/
├── features/
├── mocks/
├── pages/
├── routes/
├── services/
├── types/
└── utils/
